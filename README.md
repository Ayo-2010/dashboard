# Meridian Analytics

An analytics dashboard that runs entirely on local sample data.

## Features

- Four stat cards with values, up or down percentage change and inline SVG sparklines
- Date range chips for 7, 30 and 90 days that rescale every chart
- Canvas bar chart of twelve months with axis labels and hover tooltips
- Canvas donut chart of traffic sources with a synced interactive legend
- Sortable orders table with ten rows, clickable headers and a status filter
- Thousands separators on every number and tabular figures in the table
- Dark and light themes that redraw the charts with theme-aware colours
- Empty state row that appears when a filter matches no orders

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.
